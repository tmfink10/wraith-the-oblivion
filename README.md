# wraith-the-oblivion
Wraith: The Oblivion 20th Anniversary + The Hopeful Damned

This is meant to be run locally. Though you could host it online, there would be some additional steps to complete to make that happen. It's not hardened for the Internet either, so beware.

If you have a mac or linux box, that's going to be easiest. If you're running windows, you can try it but you might just want to get virtualbox or something else and run linux on that.

Once you have the dependencies in place, it's easy enough to get running. Just go to the wraith-the-oblivion directory and run "docker compose up -d" you can then go to your browser and go to localhost:3001

All you really need is docker engine and docker compose. Install those, and you should be good!
